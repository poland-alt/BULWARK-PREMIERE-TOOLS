# Bulwark Premiere Tools

Two Adobe Premiere Pro panels used by The Bulwark's video team:

- **Bulwark Vertical Reformat** turns a finished 16x9 sequence into a 9x16 one.
- **Bulwark Caption Tools** sets the outline width on many captions at once.

**First install:** download `Bulwark Premiere Tools.zip` from this page, unzip it and follow `README.txt`.

**Updates:** installed panels check `latest.json` here when they open and offer an "Update now" button when a
newer version is published. Nothing updates without that click.
