HOW TO ADD A THUMBNAIL TEMPLATE
===============================

Each show's thumbnail frame is a folder holding:

  template.json   the show's name, where the picture windows are for each layout (2 pictures,
                  3 pictures, ...), the divider colour, and how the headline is drawn
  the artwork     either the two textured bands (top.jpg, bottom.jpg), or one overlay.png
                  (1080x1920) with the picture windows TRANSPARENT

The headline box and the dividers are drawn by the panel, so leave them out of the artwork.

WHERE TO PUT IT
---------------
On your own Mac (kept through updates, only you see it):
  ~/Library/Application Support/Bulwark Tools/thumbnail templates/<any folder name>/
  The Thumbnail tab has a link, "Open my thumbnail templates folder", that takes you there.

For the whole team (ships in the next update): send the frame PNG to Jared. The frames that
ship were all built from the designers' "HEADLINE GOES HERE" PNGs by a script
(make_thumb_templates.py), which measures the bands and divider and writes this folder.

Frames appear in the Thumbnail tab's "Show (frame)" list; the layouts appear as chips beside
the preview. A frame whose "show" matches the show picked on the Reframe tab is listed first.

template.json
-------------
{
  "name": "TNL",                        what the list shows
  "show": "9x16 TNL",                   the show's name exactly as on the Reframe tab; "" = none
  "size": [1080, 1920],
  "bands": [                            artwork placed by position (or use "overlay": "overlay.png")
    { "file": "top.jpg", "x": 0, "y": 0 },
    { "file": "bottom.jpg", "x": 0, "y": 1682 }
  ],
  "layouts": [
    { "name": "2 pictures",
      "windows": [                      one entry per picture, in the order they are filled
        { "name": "Top",    "x": 0, "y": 239, "w": 1080, "h": 706 },
        { "name": "Bottom", "x": 0, "y": 975, "w": 1080, "h": 707 } ],
      "dividers": [ { "x": 0, "y": 945, "w": 1080, "h": 30, "color": "#D0461D" } ] },
    { "name": "3 pictures",
      "windows": [
        { "name": "Top left",  "x": 0,   "y": 239, "w": 525,  "h": 706 },
        { "name": "Top right", "x": 556, "y": 239, "w": 524,  "h": 706 },
        { "name": "Bottom",    "x": 0,   "y": 975, "w": 1080, "h": 707 } ],
      "dividers": [ { "x": 0, "y": 945, "w": 1080, "h": 30, "color": "#D0461D" },
                    { "x": 525, "y": 239, "w": 31, "h": 706, "color": "#D0461D" } ] },
    { "name": "1 picture",              one picture, no bar; "headlineCentre" is where the middle of
      "windows": [                      the title goes in this layout (leave it out to use the usual place)
        { "name": "Picture", "x": 0, "y": 239, "w": 1080, "h": 1443 } ],
      "dividers": [], "headlineCentre": 1329 }
  ],
  "headline": {
    "top": 860,                         y of the top edge of the headline box; the box grows downward
    "box": "#D0461D",                   box colour ("" = no box, text only)
    "text": "#FFFFFF",
    "font": "Special Gothic Condensed", must be installed (Adobe Fonts)
    "weight": 600,
    "capHeight": 0.722,                 height of a capital letter as a share of the font size
    "uppercase": true,
    "radius": 7,                        corner rounding of the box
    "oneLine":  { "size": 96, "maxWidth": 890, "padX": 45, "padTop": 50, "padBottom": 50 },
    "twoLines": { "size": 84, "maxWidth": 928, "padX": 25, "padTop": 34, "padBottom": 36, "gap": 46 }
  }
}

x, y, w, h are in pixels from the top left of the 1080x1920 thumbnail. A folder with a single
layout can put "windows" and "dividers" at the top level and leave "layouts" out.
In your own folder the artwork can be plain image files (top.jpg, overlay.png); the frames that
ship are stored as text (top.jpg.b64) only because that is what the panel's updater can carry.
